# 排版交付质检

只检查本次适用项，采用本次逐属性确定的有效规则；默认值仅见 [默认预设](default-format.md)，不在验收时覆盖学校规范或本次明确要求。各项记为“通过 / 待复核 / 不适用”；工具缺失、范围未覆盖或仅说明了限制均不能记为通过。发现问题时修复相关项，不为没有新依据的检查反复运行工具。

## 依据与输入

- [ ] 已确定原稿和排版依据，完整阅读实际采用的规范；无外部规范/模板时采用已确认的 [默认预设](default-format.md)。
- [ ] 本次要求、适用明确规范、模板、用户默认预设与工具默认按优先级处理，确实影响结果的未决冲突已说明。
- [ ] 必填元信息来自原稿或用户确认；没有把模板示例作为用户事实。
- [ ] 原件保留，输出为新文件或已有明确覆盖授权。
- [ ] 本次基底版本明确，连续修订未丢失此前已确认修改；已有题注、引用句、公式标签和放大区未重复插入。

## 格式落实

- [ ] 页面方向、纸张、页边距、装订线及页眉页脚距离符合采用的依据。
- [ ] 中西文字体、字号、行距、缩进、段前段后、对齐及标题层级符合要求；核对默认标题样式带入的主题色、下划线或横线，只保留规范或模板要求的样式。
- [ ] 段落实际应用的样式名、标题层级、大纲语义、字号、加粗、对齐与缩进符合本次有效规则，默认属性按预设核对；正文未误设标题层级。
- [ ] 实际生效的中文、西文和数字字体符合本次规则；已核对样式继承、主题字体、直接格式与自动编号定义，覆盖正文、标题/题注/公式编号、页码和字段结果。
- [ ] 样式设置后仅清理冲突的直接格式，正文原有局部强调、上下标、链接等有意义格式已保留。
- [ ] 可编辑数学文字符合本次字体规则；确需专用数学字体的复杂符号/结构已记录具体对象、字体与原因，未为统一字体破坏表达。
- [ ] 行距数值和类型符合本次规则，默认属性按预设核对；图段和高公式未被固定行高裁切。
- [ ] 章节分页、节、页码格式与重启、页眉页脚继承分别核对。
- [ ] 表格宽度、边框、重复表头和跨页行为，图表/公式的位置及现有题注样式符合要求。
- [ ] 目录层级、自动编号、字段及交叉引用的显示结果与最终分页一致；未刷新或未核对的字段已列为待复核。
- [ ] 字段更新范围限本次所需，未无差别刷新外部数据；已区分PDF导出所见结果与保存到DOCX的字段结果。
- [ ] 未经授权不将可更新目录改为静态目录；没有补写摘要、声明、个人信息或图表数据来源/结论。
- [ ] 图表均有准确关联的题注；缺失题注已从现有内容补中性简短标题，位置按本次有效规则核对。图/表分别检查重复、跳号、顺序、位置、SEQ 与正文引用，遵循已有有效或用户指定编号体系。
- [ ] 需用于正文的图/表均有对应编号引用；必要新增句只中性说明可见主题/内容，与题注一致，不编结果、因果或效果评价。
- [ ] 独立公式标签、位置与编号体系符合本次有效规则，编号连续且引用正确；默认体系未虚构章号。必要的独立化保留原有表达与数值，优先原生 OMML，未把普通行内数字当公式。

## 内容与对象保全

- [ ] 对比使用了明确且可解释的范围，所有用户文字、表格值、数字、姓名、日期、术语、引文及 URL 的差异均已处理或列为待复核。
- [ ] 新增题注/必要图表引用句、公式独立展示与标签、四级标题前缀、相关引用号、目录、页码等授权差异及固定模板文字与原文分开记录，没有为消除差异任意排除内容；未冒称全部文字零改。
- [ ] 公式、图片、文本框、脚注/尾注、批注、链接、书签、嵌入对象和修订等实际存在对象已核对；无纯文本重建造成的遗漏。
- [ ] 链接目标、交叉引用关系、自动编号语义和字段显示结果已人工/结构核对，未用文字相同代替关系完整。
- [ ] 未自行接受/拒绝修订或删除批注，未改写未获授权的内容。
- [ ] 书签及其引用默认保全；任务内明确授权的处理仅限该范围，未把先前个别作业的删除授权作为默认规则。
- [ ] compare_text.py 的退出码、范围和需复核提示已按 [validation.md](validation.md) 解释；--loose 或脚本一致结果不单独证明全文无变更。

## 模板清理

- [ ] 适用的固定声明与有效结构保留，明确的占位内容和无关示例已替换/删除。
- [ ] 已识别的旧题目、旧作者、示例正文及模板页眉页脚残留已搜索核对，未误删原稿中的合法同名文字。
- [ ] 最终字段、封面和元信息未保留误导性的模板值。

## 视觉验收与交付

- [ ] 首次渲染前已完成有效样式、直接覆盖、节方向、图题关联、编号/引用及内容差异的结构检查。
- [ ] 渲染可用时已渲染最终文件，全部最终页面均有审阅依据，无重叠、裁切、缺字、异常留白、孤立标题或表格越界；沿用旧页审阅记录时已确认新旧渲染页像素完全相同。
- [ ] 每页大面积空白已审查，修正不合理 keepNext、分页/分节或图片尺寸；末页自然留白与中间页异常空白分别判断并尽量均衡。
- [ ] 图片等比且清晰，版面按本次有效规则核对；采用默认时，无横向独占图页，放不下的图题移下一纵向页开头，正文前后接排、顺序及引用正确，无人为大空白。
- [ ] 如因图内小字增加局部放大区，已保留全图并清楚标识放大区域，同组题注、正文引用和图后接排正确，未改动图内文字或数据。
- [ ] 未靠缩小正文、压缩既定行距、拉伸图片、过度放大低清图或无关内容填白。
- [ ] 最后一次影响分页的修改后已重新核对页码、目录和相关交叉引用。
- [ ] 无法渲染时明确写明“未完成视觉验收”、原因与待核对事项；此项保持待复核，不以说明代替通过。
- [ ] 最终链接可定位，交付说明区分已完成检查、已解释差异、待复核范围和工具限制；没有概括为未经验证的“全文不变”。
